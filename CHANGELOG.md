# THE LISTER - CHANGELOG ✨

## Version 2.0 🚀

### New Features
- **Enhanced Celebration System** 🎉: Choose between different celebration effects when completing all tasks
  - **Pixel Fireworks** 🎆: Improved version of the original confetti with more pixel art aesthetic
  - **Raining Confetti** 🌧️: New black and white confetti pieces that rain down from the top of the screen
  - **Random Mode + Song Gift** 🎵: Randomly selects between celebration effects with a chance to get a song reward

- **Song Rewards** 🎧: When using Random Mode, there's a chance to receive a random celebratory song when completing all tasks
  - Songs are selected from a curated playlist of upbeat, popular tracks
  - Presented in a congratulatory dialog box

### Improvements
- **Celebration Menu** ⚙️: Dedicated settings panel for selecting celebration styles
- **More Refined UI** 💅: Further polish to the minimal neo-brutalist design
- **Expanded Help Documentation** 📚: Added information about new features

## Version 1.0 🏆

Initial release with functionality:
- **Core Task Management** ✅:
  - Create, edit, delete, and reorder list items
  - Mark items as completed with checkbox
  - Drag and drop to rearrange items

- **Visual Design** 🎨:
  - Minimal neo-brutalist design aesthetic
  - Dark/Light mode toggle with pixel art sun/moon icon
  - Customizable colors and fonts

- **Productivity Features** ⚡:
  - Keyboard shortcuts for navigation and actions
  - Task shuffling to overcome procrastination
  - Visit counter to track usage
  - Markdown export/import functionality

- **User Experience** 🌟:
  - Simple confetti celebration when completing all tasks
  - Local storage for automatic saving
  - Help dialog with keyboard shortcuts and feature explanations
